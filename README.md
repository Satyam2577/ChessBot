ChessBot


Overview

ChessBot is a web-based chess application that allows users to play chess against an AI engine. The application features a graphical chessboard, move history, and the ability to take back moves or start a new game.

Features

Play chess against an AI opponent.
Drag and drop pieces on the chessboard.
View move history in a table format.
Take back moves and reset the game.
Adjustable AI difficulty levels.


Technologies Used

Frontend:


HTML

CSS


JavaScript (jQuery)

Bootstrap for styling

Chessboard.js for the chessboard interface

Chess.js for chess logic


Backend:



Python

Flask web framework

Chess library for AI engine
